Praktikum · Organisation

Foliensatz

Praktikumsblatt 1 · Keyboard Hacking

Sie zerlegen eine Tastatur und bauen sie zu einem eigenen Eingabegerät um. Sie löten, verdrahten die Matrix neu und dokumentieren jeden Schritt in einem gemeinsamen Padlet. Am Ende haben Sie ein Gerät, das Tastendrücke auslöst, ohne wie eine Tastatur auszusehen. Dazu kommt ein Protokoll, das zeigt, wie Sie dorthin gekommen sind.

Blatt als PDF Foliensatz zum Termin

Praktikumsblatt 2 · Visuelle Programmierung mit vvvv

Sie vertiefen die Arbeit mit der visuellen Programmierumgebung vvvv. Sie bauen Patches von Grund auf, nutzen die Maus als eindimensionalen Positionsgeber und entwickeln daraus eine Anwendung, mit der Sie Punkte von Interesse in einem Hintergrundbild ansteuern. Sie programmieren, indem Sie Knoten verbinden, nicht indem Sie Code schreiben.

Blatt als PDF Foliensatz zum Termin

Praktikumsblatt 3 · Arduino-Einführung mit I/O

Sie arbeiten zum ersten Mal mit dem Arduino. Sie schreiben ein erstes Programm, schließen Sensoren und Aktoren an und lassen das Board eigenständig auf Eingaben reagieren. Zum Schluss kommt die drahtlose Kommunikation dazu. Damit haben Sie die Grundlage für alle weiteren Arduino-Blätter dieses Praktikums.

Blatt als PDF Foliensatz zum Termin

Praktikumsblatt 4 · Arduino: Ultraschall, IR und Displays

Sie erweitern den Arduino um Ausgabe und Abstandsmessung. Sie geben Text und Grafik auf einem OLED-Display aus, binden Infrarotsensoren an, probieren weitere Displaytypen aus und messen mit Ultraschall Entfernungen. Die letzte Aufgabe ist bewusst offen gehalten: Dort kombinieren Sie die Bausteine zu etwas Eigenem.

Blatt als PDF Foliensatz zum Termin

Praktikumsblatt 5 · Arduino und vvvv koppeln

Sie koppeln die beiden Werkzeuge der vorigen Blätter: Der Arduino liefert Messwerte, vvvv verarbeitet sie und zeigt sie an. Zuerst richten Sie die Verbindung von Hand ein, dann wechseln Sie auf das Firmata-Protokoll, das die Kopplung deutlich vereinfacht. Am Ende haben Sie eine Anwendung, die die Temperatur einer Kaffeetasse sichtbar macht.

Blatt als PDF Foliensatz zum Termin

Praktikumsblatt 6 · Face- und Fiducialtracking

Sie arbeiten mit kamerabasierter Erkennung in vvvv. Sie lassen Gesichter in einem Video und im Kamera-Livestream finden und verfolgen anschließend Fiducial-Marker: gedruckte Muster, die sich zuverlässiger erkennen lassen als ein Gesicht. Beide Verfahren liefern Positionen, auf die eine Anwendung reagieren kann.
